# 钓鱼游戏 · 黄金大海捞（v3）

在浏览器中打开即可游玩，自动铺满全屏（手机竖屏、横屏、电脑任意比例都没有黑边）。

- 完整版：https://zhangjianlin0316-stack.github.io/fishing-game/
- 轻量版（网络慢时用）：https://zhangjianlin0316-stack.github.io/fishing-game/lite.html

## 玩法
- 鱼钩在船底的滑轮下左右摆动，整整 180°。按空格、点击或触摸屏幕放钩。
- 鱼钩碰到的第一条鱼就会被钩住：浅海成群的小鱼会挡路，想钓深海大鱼要找准空隙。
- 每关 60 秒，分数达到目标就过关，过关后可以进商店买道具。
- 道具用键盘 1–5 或点底部按钮：双钩 / 加时间 / 冰冻 / 驱散小鱼 / 强力药水。
- 道具掉落：钓到中下层以下的大鱼、宝箱或漂浮的「道具泡泡」都会掉落道具，自动飞进道具栏。越深掉率越高（海底 55%，黄金大螃蟹必掉 2 个）。
- 全屏：右上角全屏按钮或按 F 键；首次点击屏幕时会自动请求全屏（浏览器允许时）。

## 每关不同的海底场景
| 关卡 | 场景 |
|---|---|
| 第 1、5、9… 关 | 珊瑚礁（白天） |
| 第 2、6… 关 | 沉船遗迹（黄昏） |
| 第 3、7… 关 | 失落古城（紫色暮光） |
| 第 4、8… 关 | 深海海沟（夜晚，发光浮游生物） |

背景是动态的：摇曳的海带、移动的焦散光纹、会漂移闪烁的光柱、上升的气泡、漂浮的浮游生物、远处缓缓游过的大鱼剪影，海水颜色也会随时间缓慢变化，换关时淡入淡出。

## 30 种海洋生物（共 5 层，越往深处数量越少、分值越高、奖励越多）
| 层 | 种类 | 分值 | 额外奖励 |
|---|---|---|---|
| 浅海（8 种，数量最多，成群挡钩） | 沙丁鱼、小虾、小丑鱼、小黄鱼、青鳞鱼、蓝吊鱼、皇家紫鱼、水母 | 2–15 | — |
| 中上层（7 种） | 神仙鱼、河豚、黄箱鲀、海马、狮子鱼、乌贼、金枪鱼 | 30–100 | — |
| 中下层（6 种） | 红石斑、海龟、海鳗、玳瑁、魔鬼鱼、剑鱼 | 160–380 | +15% |
| 深海（5 种） | 鲨鱼、章鱼、锤头鲨、幽灵章鱼、鮟鱇鱼 | 450–800 | +25% |
| 海底（4 种，数量最少） | 帝王蟹、蓝龙虾、珍珠贝、**黄金大螃蟹** | 1000–3000 | +40%（黄金蟹 +50%） |

鱼的动作：悬停、突然冲刺、转身、成群游动、低头觅食、鱼钩靠近时受惊逃开、大鱼追小鱼（追上会吃掉）。
特效：鳞片闪光、稀有生物光环（黄金蟹旋转金光）、游动气泡尾迹、钓中时水花和波纹、分数弹跳、稀有大奖全屏闪光和横幅、冰冻时结冰边框和冰块。
